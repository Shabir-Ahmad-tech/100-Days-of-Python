# 🐍 100 Days of Python

A focused, hands-on journey to master Python by building **one new project every day for 100 days**.

This repository is not about watching tutorials or copying code.
It is about **learning by building**, making mistakes, fixing them, and improving every single day.

---

## 📌 What This Repository Is About

* 100 days of consistent Python practice
* 100 practical projects (small to medium scale)
* Real problem-solving, not toy examples
* Clean, readable, and improving code over time

Each project represents a single day of learning and execution. Some projects are simple. Some are challenging. That’s intentional — progress beats perfection.

---

## 🛠️ What You’ll Find Inside

* Python fundamentals (syntax, logic, functions)
* Data structures and algorithms
* File handling and automation
* APIs and web-related scripts
* Beginner to intermediate projects
* Gradual improvement in code structure and design

Every folder/day contains:

* Source code
* A short explanation of the project
* Key concepts learned that day

---

## 🎯 Why This Challenge

Consistency builds skill.

Instead of waiting to feel “ready,” this challenge focuses on:

* Writing code daily
* Thinking like a problem solver
* Building a public portfolio
* Developing discipline and momentum

By the end of 100 days, the goal is to be **confident, job-ready, and comfortable building real Python applications**.

---

## 🚀 How to Use This Repository

* Browse projects by day
* Clone the repository and run the scripts locally
* Learn from earlier mistakes and later improvements
* Use it as inspiration for your own 100-day challenge

```bash
git clone https://github.com/Shabir-Ahmad-tech/100-days-of-python.git
cd 100-days-of-python
```
